## Context

См. proposal.md. Лендинг статический, фотографии и афиши локальные. В Glamdance уже используется yet-another-react-lightbox с Thumbnails и Zoom.

## Goals / Non-Goals

Полноэкранный просмотр на desktop и mobile с доступным управлением. Новые маршруты и сервер не требуются.

## Decisions

- Использовать существующий в Glamdance паттерн Lightbox с Zoom и условным Thumbnails. Самописный диалог потребовал бы повторять управление фокусом, свайпы и масштабирование.
- Для фотографий единый массив из шести слайдов; для постера — ровно один слайд, конечная карусель без навигационных стрелок и миниатюр.
- Просмотр остаётся полноэкранным на обеих ширинах по существующему паттерну PortfolioLightbox, а не превращается в форму со шторкой. Действия внутри стороннего viewer сохраняют его доступную разметку.
- Ссылки изображений сохраняют href оригинального локального файла; React перехватывает обычный клик для просмотра на странице.
- Афиша шириной 460 px на большом экране, 340 px на планшете и 100% контейнера на телефоне. Новые фото подготовить из исходников в WebP.

## Risks / Trade-offs

Дополнительный JavaScript → загрузка viewer через React.lazy только после выбора изображения. Регрессия кликов, фокуса и мобильных жестов → Chromium E2E, это нельзя доказать тестом данных.

## Migration Plan

Проверки, commit, push и существующий workflow GitHub Pages. Откат — revert commit приложения.
