## Context

Новый независимый статический репозиторий, публикация GitHub Pages. Данные организатора ограничены афишей; фотографии переданы пользователем.

## Goals / Non-Goals

**Goals:** минимальный лендинг с локальными WebP, проверяемыми ссылками и доступными интеракциями.

**Non-Goals:** сервер, оплата, формы с хранением персональных данных, реальное управление остатками.

## Decisions

- Vite + React + Mantine по запросу пользователя; GitHub Actions собирает статический `dist` с base `/aksenovdance/`.
- Скопировать существующие AppButton, AppHeading, AppText и токены Glamdance, локальные Roboto/Roboto Serif, светлую тёплую палитру. Новый сайт не требует TanStack Start или серверного стека основного продукта.
- Нативные якоря для разделов одной страницы, sticky navigation с отслеживанием позиции разделов и горизонтальным скроллом на mobile. Это не переходы между маршрутами.
- Цены и доступность — подписанные демонстрационные fixtures; связь — реальный tel организатора. Разворачиваемые строки вместо дополнительных модальных поверхностей.
- Список тренеров из афиши, миниатюры вырезаны из переданного изображения. Сервисы взяты из публичного каталога; участие не заявляется подтверждённым.

## Risks / Trade-offs

- [Примерные цены могут принять за реальные] → заметная маркировка страницы и каждого раздела с ценами.
- [Небольшие портреты в афише] → ограниченные размеры аватаров, без увеличения до полноэкранных фото.
- [Неподтверждённая программа] → нейтральные редакционные подписи и прямой контакт организатора.
